# Bali Jejepan Implementation

Reference layer for the six-value Jejepan cycle.

- Values: Mina, Taru, Sato, Patra, Wong, Paksi.
- Mapping: Pawukon day modulo 6.
- Modulus 0 = Paksi; 1 = Mina; 2 = Taru; 3 = Sato; 4 = Patra; 5 = Wong.
- No interpretation or ramalan logic is included.

Reference basis: Babad Bali's Paringkelan documentation and SakaCalendar's Jejepan table.
