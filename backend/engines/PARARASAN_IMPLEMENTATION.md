# Bali Pararasan

This layer preserves two documented Pararasan variants without treating either as universal.

## Variants

- Babad Bali: 10-value variant.
- Sakacalendar: 12-value variant.

The approved research audit established the value sets and cycle sizes, but did not establish a sufficiently verified input/index formula that can be safely implemented as a calculation rule.

Therefore this implementation exposes the variant registry only. It deliberately does not infer a formula, select a canonical variant, or add interpretation/ramalan logic.
